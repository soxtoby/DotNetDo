# NuGet CLI is host-owned

`Tools.NuGet` models every non-deprecated command and option with a current official `nuget.exe` reference page, including security commands omitted from the reference index, except for the help command because it adds no task-automation capability and `Update -Self` because executable updates belong to the host installer. Commands remain platform-neutral and may run wherever a host-provided `nuget` executable works, including best-effort Mono environments; `Tools.NuGet.EnsureAvailable` can install the executable only on Windows through Scoop. Execution never installs it, and DotNetDo neither extracts `NuGet.CommandLine` nor downloads or pins an executable. This preserves the existing availability-not-version contract, avoids a new cache and binary-provenance lifecycle, and lets the executable reject unsupported syntax natively.
