# API reference

DotNetDo.Core APIs are arranged by what a task needs to do. Entry points such as `Do.Exec()` and `Tools.DotNet.Build` appear in their family with their complete generated documentation. Supporting types have canonical generated pages.

## Core APIs

See the [core API overview](core/index.md) for execution, parameters and secrets, paths and files, the workspace and its solution, Git repositories, CI and logging, and the shared string and collection utilities.

## Tools

See the [tool API overview](tools/index.md) for Azure and Bicep, Bun, the .NET SDK, Git, GitVersion, MSBuild, npm, NuGet, Scoop, and VSTest.
